# Cover Image Concept — FirstVoice

## Option 1: Split Scene (Recommended)

**Layout:** 16:9 ratio, split diagonally

**Left side (dark/disaster):**
- Collapsed building rubble, dust
- A hand reaching out
- Muted colors (grey, brown)

**Right side (bright/hope):**
- Phone screen showing FirstVoice conversation (Hindi ↔ English)
- Clean, bright UI with chat bubbles
- Gemma 4 logo subtly visible

**Center overlay text:**
- "FirstVoice" (large, white, bold)
- "Offline Multilingual Crisis Communication" (smaller, below)
- "Powered by Gemma 4" (bottom, with Gemma logo)

**Bottom bar:** "🎤 Audio → 🌐 Translate → 📋 Triage → 📡 Mesh Sync"

## How to Create

**Quick option:** Use Canva or Figma with:
- Screenshot of the app (encounter screen with Hindi/English conversation)
- Gradient background
- Text overlays
- Gemma 4 logo (from Google's press kit)

**Size:** 1920x1080 or 1280x720 (16:9), JPG/PNG, under 3MB
