# FirstVoice Web Demo

Kaggle Colab notebook with Gradio UI for the hackathon live demo.

## Setup

1. Open `firstvoice_demo.ipynb` in Kaggle or Google Colab
2. Select a GPU runtime (T4 or better)
3. Run all cells
4. Access the Gradio interface via the generated public URL

## Model

Uses Gemma 4 26B-A4B for full model capabilities.
